# Kairos 1.0.5 — 2026-11-05

## Changes

- Optional background AI refinement after committing the original and resuming playback; original/AI versions remain in Dashboard and Markdown exports.
- Localized AI switches in the sidebar header and expanded island; missing configuration opens Settings without an expected background error.
- Lower-center note editor, draggable blue handle and persistent video-relative placement. Playback previews use the same placement, preserve hover-to-read behavior and fit the available video area.
- Pinned island becomes transparent with reduced blur when idle; interaction restores readability.
- Website product screenshot, note/refinement walkthrough, illustrative provider settings and updated privacy disclosure.

## Validation

Passed: `test/ai-providers.mjs`, `test/summary.mjs`, `test/i18n.mjs`, `test/popup.mjs`, `test/storage-browser.mjs`, `test/refinement-browser.mjs`, `test/note-placement-browser.mjs`, `test/dashboard-browser.mjs`, and `website/scripts/check.mjs`.

The remainder of that suite and real-site native fullscreen behavior have not been verified for this release.
