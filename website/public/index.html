你可能想知道

现在支持哪些视频平台？＋

目前支持桌面 Chrome 浏览器中的 YouTube 和哔哩哔哩视频页面，支持普通播放和全屏。移动端暂不支持。

不使用 AI，也可以记笔记吗？＋

可以。手动记录、截图和回看不需要 AI 密钥。AI 辅助笔记和总结需要配置提供商账号，并按其规则计费。

我的笔记和截图会被发到哪里？＋

笔记保存在当前浏览器的本地数据库。触发 AI 笔记时，画面与字幕上下文发送到你选择的提供商；生成总结只发送文字笔记与字幕上下文。密钥通过 Chrome 同步存储保存，OpenRouter 会将请求转发给其模型供应商。

可以迁出我的笔记吗？＋

可以导出 Markdown，或将总结下载为分享长图。建议定期导出，卸载扩展或清除扩展数据可能移除本地笔记。

如何安装？需要付费吗？＋

可从 Chrome 网上应用店免费安装，也可通过下方源码安装步骤自行构建。AI 服务的额度与费用由你选择的提供商决定。

  1. 获取项目

    从 GitHub 克隆或下载源码，安装 Node.js 与 pnpm。

  2. 构建扩展

    在项目根目录运行：

    pnpm install
pnpm build
  3. 加载到 Chrome

    打开 chrome://extensions，开启「开发者模式」，选择「加载已解压的扩展程序」，选中项目中的 dist 文件夹。

  4. 打开一个视频

    刷新 YouTube 或哔哩哔哩视频页，点击 Kairos 的「启用」。需要 AI 时，再前往设置填写密钥。
